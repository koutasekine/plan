## 3. 承認された対応表

### 3.1 置き換える語

- WBS の末端の要素を指す「作業」は、すべて「タスク」にする。助詞がついた形(作業の・が・を・に・は・も・と・か・だけ)、複合語(作業の表・作業ごと・作業の棒・作業の行・作業の箱・作業の矢印・作業の状態・作業の日数・作業の件数・作業の期間・作業の長さ・作業の量・作業の範囲・作業の進み具合・作業名・作業の担当者・作業の重なり・作業すべて・末端の作業・○○のための作業・作成する作業・確認する作業・先行する作業・先の作業・後の作業・前の作業・次の作業・隣り合う作業・ほかの作業・最後の作業・○ 作業・作業 ○ 件・作業が進む日・作業が止まり・作業は中断して・作業が多い/少ない・作業が集中する・作業が偏らない・作業を並べる・作業を選ぶ・テストの作業・頼まれた作業)も同じ。
- 列の見出しの「活動タスク」は「タスク」にする。
- 「作業(活動タスク)」は「タスク」にする(かっこを消す)。
- 「試験作業」は「試験のタスク」にする。
- 仕様書 2 章の用語の表は「タスク | WBS の末端の要素(資料の「活動タスク」)」とする(資料の言い方として「活動タスク」は残す)。
- コードの注釈も同じ規則で置き換える。

### 3.2 置き換えない語

| 語 | 理由 |
|---|---|
| 作業日 | 暦の上の働く日 |
| 作業できる日・作業できない日・作業できる日数 | 人が働ける日 |
| 作業できる長さ | 働ける時間の長さ |
| 作業時間 | 働いた時間の記録 |
| ダミー作業 | アローダイアグラムの依存だけを表す点線の矢印。末端の要素ではない |
| 作業の木・作業(WBS) | WBS 全体を指す(WBS は作業分解構成)。「作業の木。末端の要素がタスク」と並べて書く |
| 「WBS は、PBS の要素を作るための作業を分解します」(AI 用のプロンプト) | WBS が分解する仕事の全体を指す |
| 作成者・確認者、記法のキーワード、エラーの記号(C4 など) | 対象外 |
